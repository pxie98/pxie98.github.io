OPEN RESEARCH NOTE · 27 NOVEMBER 2026

AI 的下一次
数学突破，在哪里？

AI4Math Forecast: graph-based modeling of AI-assisted mathematical progress.

从数学子领域的突破记录出发，结合知识结构、时间变化与验证证据，研究未来的突破是否具有可预测性。

01 / RESEARCH QUESTION

把一个直觉变成可证伪的问题

初始设想是：把数学的各个小领域作为“插值点”，把 AI 最近解决的问题数量、难度与贡献作为观测值，用动态代理模型推测下一处突破。这里保留这一核心想法，同时对空间、事件和预测目标作严格定义。

给定时刻 t 之前可获得的证据，能否比“历史活跃领域继续活跃”等简单基线，更准确地预测某子领域在未来 180 天内出现至少一次经验证的 AI 参与开放问题解决事件？

定义 yi,t,H = 1，当且仅当领域 i 在 (t, t+H] 内至少出现一次符合预先登记标准的事件。默认研究窗口 H = 180 天，并在 90、365 天下检验稳健性。这是多个领域各自的二元事件预测：多个领域可以同时发生突破，概率不必加总为 1。若研究“全数学下一次事件属于哪里”，则需另设竞争风险模型，不能混用这两个目标。

学科不是欧氏坐标

MSC 分类编号是类别标识，不能把编号差当作数学距离。以细粒度 MSC 主题为节点，利用截断时间之前的共分类、引用与可验证的共享方法建立加权图，再比较图核与嵌入模型。

预测与优化分别评估

被动观察历史首先得到预测任务。只有能选择研究方向、分配计算或人工验证预算，并获得后续反馈，才形成预算约束的序贯决策问题。DFO 或贝叶斯优化是后续研究路线，不自动赋予预测模型收敛保证。

English summary. This project asks whether a time-aware graph of mathematical subfields improves forecasts of independently verified AI-assisted open-problem resolutions. We propose an auditable event registry, leakage-controlled temporal evaluation, and a separate budgeted research-allocation layer. The released baseline uses synthetic data only; no predictive validity or research priority ranking is claimed.

02 / EVIDENCE BEFORE RANKING

什么才算一次突破？

以下是用于设计标签的代表性原始文献，不是完整历史数据库或截至 2026 年的最新成果榜单。这些案例也没有被转换成演示里的事件数量或难度分数。

代表性研究与标注边界
研究可支持的判断数据记录时的边界
Davies et al., 2021机器学习辅助数学直觉，在纽结理论与表示论研究中发现结构。逐项记录定理、猜想或候选算法；不能将整篇论文视为多个已解决开放问题。
AlphaTensor, 2022以强化学习发现矩阵乘法算法。记录适用维数、数域与成本模型；算法改进不是一般矩阵乘法复杂度问题的解决。
FunSearch, 2023 online / 2024 volume程序搜索发现 cap set 新构造及在线装箱启发式。改进下界与完全解决问题分开；在线公布时间与期刊卷期时间分开。
AlphaGeometry, 2024展示奥数几何自动推理能力。竞赛题表现属于能力指标，不能直接当作研究级开放问题的解决事件。

先有可审计的事件表，再谈学科得分

每条记录需要：稳定的 problem_id 与 event_id、问题陈述、是否在研究开始前公开未解、MSC 多标签、结果类型、首次公开时间、首次独立验证可获得时间、AI 系统与角色、人工参与过程、原始文献和证明链接、验证方式、难度标注依据、审核者及修改历史。同一结果的预印本、期刊版和新闻稿去重；同一问题的后续改进作为有关联的新事件保存。

  • 严格主终点：此前公开未解的问题，经独立专家核查或可复现的形式化检查确认解决；形式化验证仍需检查形式化陈述是否对应原问题、假设和公理是否合适。
  • 分开的辅助终点：界的改进、算法发现、猜想提出、已知定理的形式化、竞赛表现。它们可提供预测特征，但不混入严格主终点计数。
  • 待核实 / 有争议 / 撤回：保存证据与状态变更；未验证事件不计入主终点。没有收录记录不等于没有进展，应标记覆盖范围与缺失程度。

建议由两位领域标注者独立审核，再记录分歧与裁决。难度使用预先定义的分档与不确定区间，不能仅凭“悬而未决的年数”认定。AI 贡献等级是待检验的测量约定，不是论文事实自带的数值。

03 / MODEL DESIGN

从累计突破，走向时间与结构

1. 保留累计指标，但用窗口增量刻画变化

Fi(t) = Σe: τₑ ≤ t aie qₑ wₑ dₑ
vi(t; Δ) = [Fi(t) − Fi(t−Δ)] / Δ

τₑ 是验证证据首次可获得的时间；aie 是跨领域分摊比例（每个事件加总为 1）；qₑ 是是否符合主终点的二元门槛；wₑ 是 AI 贡献权重；dₑ 是难度。保留图片中的 1 / 0.5 / 0.2 作为独立完成 / 合作 / 重要辅助的演示权重，未验证事件以 qₑ = 0 排除。真实研究须比较等权、不同贡献权重、难度分档及不使用难度的结果。

累计得分反映历史，不等于下一次突破概率。窗口速度也受领域规模、投入、发表延迟和报道热度影响。若有可靠的研究投入或活动问题数，可作为暴露量建模；若没有，须明确这些因素不可识别，不能把报道较多误称为更容易突破。

2. 一个可复现的图平滑基线

ŝ = arg mins ‖s − v‖² + λ sᵀLs = (I + λL)−1v， L = D − A

在对称、非负的学科关联图上，拉普拉斯矩阵 L 为半正定，因此 λ ≥ 0 时解唯一。λ = 0 返回原始速度；增大 λ 使相连领域的得分更接近。它只表达“相邻领域进展可能相关”的假设，图边不是突破传播的因果证据。该基线输出的是平滑活动分数，不是概率，也没有预测区间。

3. 在数据充分后比较真正的预测模型

先建立总体发生率、各领域历史频率、最近窗口速度，以及不使用图结构的正则化逻辑回归基线。再比较离散时间生存模型或计数模型与带图结构的模型。可研究时空核 K((i,t),(j,t′)) = [exp(−βL)]ij ktime(t,t′)，结合二元或计数似然；图扩散核的依据见 Kondor & Lafferty (2002)。图关系、嵌入、参数和概率校准都必须仅由训练期信息得到。

稀有事件可采用跨领域部分汇聚，避免少量事件产生极端估计。事件数量不足时应报告“证据不足”，而不是强行拟合深层图神经网络。代理模型的方差不自动是可靠的预测不确定性；概率校准与区间覆盖率需要独立时间段验证。

4. 从预测到研究资源分配

若未来能记录每次计算实验或人工核查的成本与结果，可以研究“预期信息增益或验证收益 / 成本”的采集策略，并保留探索预算。此时行动会改变观测分布，应与被动预测分开评估。真实学科空间不是任意可查询的光滑黑箱；现有 DFO 理论能否适用，需要重新检查局部几何、噪声、平稳性与预算假设。

05 / HOW WE WOULD TEST IT

成功标准不是一张好看的排行榜

  1. 登记协议与建立数据集

    冻结问题定义、标签规则、领域粒度、数据源和验证标准。保存公开日与验证日；建立可追溯、可更正的数据版本。先验证收集流程可重复，再决定是否有足够事件做统计预测。

  2. 滚动时间回测

    在每个历史截断点训练，只使用当时可获得的信息，预测未来 180 天。训练标签的观察窗口必须在截断点前结束；测试末尾未满 180 天的样本作删失或排除。所有图边、特征标准化、参数选择、校准和难度标注均须防止未来信息泄漏。

  3. 评价概率与排序

    概率主指标采用 Brier score、对数损失与可靠性图，和整体发生率基线比较；稀有事件同时报告 PR-AUC、事件率与样本数。Top-k 命中率作为辅助指标，事先固定 k。使用按时间块的重采样或非重叠窗口估计不确定性，不能把重叠预测窗口当作独立样本。

  4. 做能推翻假设的消融

    比较不使用图、置乱图、仅历史频率、不同窗口和贡献权重；单独剔除高报道度实验室、改变标签粒度与验证延迟。若图模型不能稳定优于简单基线，就不能声称数学知识结构提高了可预测性。

  5. 前瞻记录后再谈实时系统

    按固定节奏冻结预测并公开时间戳，等待标签窗口结束再评分。后续可建立自动发现候选文献、人工复核后更新的管道。目前页面没有自动抓取、持续更新或真实概率服务。

当前完成与待完成

已完成：研究问题与标签协议草案、代表性文献核查、依赖标准库的图平滑实现、合成事件及交互演示。尚待完成：真实事件的系统收集与双人审核、历史知识图构建、模型训练、时间回测、概率校准和前瞻验证。当前不对任何数学子领域作真实的“下一个突破”结论。
