# Pengcheng Xie Website

Personal academic website generated with `jemdoc`.

## Build

Run all page builds from the repository root:

```bash
./build.sh
```

This regenerates:

- `index.html`
- `research.html`
- `research-highlights.html`
- `publication.html`
- `talks.html`
- `mentorship.html`
- `codes.html`
- `blog.html`

## Local Preview

Start a local static server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Notes

- Keep `xpcpublication.bib` in the repository root; the publications page loads it through BibBase.
- The menu label is `Software`, while the generated page remains `codes.html` for link stability.
- Research Highlights is linked from Research and Publications. Edit `research-highlights.jemdoc` to update its six papers and contribution statements; its scoped styling and mobile layout live in `research-highlights.css` and `research-highlights.conf`.
- To rebuild only the highlights page, run `python3 jemdoc.py -c research-highlights.conf research-highlights.jemdoc`. Paper section IDs are stable links for sharing individual highlights.

The album is temporarily unpublished. Its source and photos are backed up in a separate private repository. Do not regenerate or restore the album as part of routine site builds.

## AI4Math Forecast

`ai4math.html` is a hand-maintained research proposal with scoped styling in `ai4math/style.css`; it is not generated by jemdoc. Homepage, Research, and Blog links live in their corresponding `.jemdoc` sources.

The interactive demonstration uses entirely synthetic events and a hand-specified graph. It is not a trained forecasting model or a real-world ranking. Reproduce all nine scenarios and run checks:

```bash
python3 ai4math/model.py
(cd ai4math && python3 -m unittest test_model.py)
```

`ai4math/demo-data.js` is generated from `model.py` and `synthetic-events.json`; `demo.js` selects and renders these results locally without external services. The source images motivated the research note; they are not republished.
